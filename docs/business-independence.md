## 管理调试与业务委托

管理工作区身份不包含业务主体委托。对于声明需要受信业务主体的工具，管理页调试按现有策略返回 `TOOL_FORBIDDEN`，并展示“工具缺少符合约定的受信业务主体”；此时源业务工具没有被执行。记录保留这次拒绝，随后由已配置的测试环境发布映射、服务 Key、独立委托密钥及当前主体复核完成真实后端调用。不能为了让管理调试显示成功而取消工具主体要求、给管理员伪造业务主体或放行生产发布。

模型能力与提示词属于测试前置配置。模型响应、供应商能力证明和 Token 用量由受控替身提供；MCP 结果、身份复核与 HTTP 鉴权实际执行。运行调用正式 Worker 入口，测试进程承担消息投递，不声称已经验证独立 Celery 部署。完整范围见验收记录。

## 业务接入清单

| 事项 | 业务方提供 | Creativity 配置及核对 |
| --- | --- | --- |
| 权限边界 | 源用户身份、组织/数据域编号、当前动作与资源权限 | 开通渠道、环境、显式数据域映射、接入服务及权限 |
| 业务工具 | MCP 地址、认证方式、工具名称、输入输出 schema、真实影响、超时及错误语义 | 出站目的地配置、MCP 凭据、发现快照、工具导入/授权/冻结/发布 |
| 当前主体复核 | 可收窄的当前权限、停用状态、观测时间及短期有效期 | 绑定专用身份工具；复核工具不进入模型工具目录 |
| 任务方法 | 技能指令、领域政策资料、源数据缺失及部分结果的解释 | 导入 Skill，显式绑定本渠道工具，选择资料与版本 |
| 模型与编排 | 任务输入、期望输出、业务效果样本 | 选择已验证模型路由与提示词，配置 Agent schema、步骤、工具白名单、限制与发布策略 |
| 后端调用 | 在自己的后端保管秘密，从当前登录及权限服务读取主体，持久化幂等键/run_id/SSE 游标 | Key 换 Token、校验委托、统一运行 API、当前权限重查、用量和来源记录 |
| 变更与撤销 | 工具或政策版本变更、授权撤销通知和重新验证 | 发现新契约、创建候选版本、重新授权与发布；旧版本不静默升级 |
| 业务验收 | 领域计算、数据正确性、政策有效性、业务页面和上线决定 | 通用隔离、版本、输出结构、错误、来源及 API 运行保障 |

所有秘密留在各自后端；交付配置只包含占位引用和受控测试值。源系统继续负责领域授权、事实、规则及确定性计算。实际租号或陪玩接入可采用此清单，各自上线和业务效果在对应项目验收，不构成本平台的固定发布前置。
