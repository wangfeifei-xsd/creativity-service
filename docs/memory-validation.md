# 13 结构化记忆管理验收记录

日期：2026-10-02。实现及跨模块边界见 [记忆交接](memory.md)。服务测试使用真实本地 PostgreSQL 和 Redis 的隔离范围；运行定义和工具结果为测试夹具，不代表真实 Agent、模型供应商或业务工具已经联调。

| 验收 | 自动验证内容 |
| --- | --- |
| MEM-A01 / F02/F03 | 单次任务条件不落库；推断候选不能作为事实检索；确认后才生效 |
| MEM-A02 | 明确保存带来源和版本；当前任务属性优先；加载计数与检索记录可追踪 |
| MEM-A03/A08 | 相同主体编号、相同属性在渠道、环境、数据域、主体类型及主体编号间互不命中或清空；引用缓存键不同；游标绑定 Scope；浏览器切换渠道清理旧数据 |
| MEM-A04 | 单项遗忘立即使旧引用失效；值和历史原文不可读；删除任务幂等且可查询；本地清理等待后续传播 |
| MEM-A05 / F09 | 来源删除前后复核；独占来源项撤销，独立来源保留；已删来源标题与历史内容不再暴露；真实会话删除图能区分两种记忆 |
| MEM-A06 / F01/F10 | 关闭禁止检索和自动写入，保留记忆详情及正常会话；清空不修改开关；重新开启不复活旧选择；旧任务和旧来源不能把已遗忘内容重新写回，重复清空推进阻断时间 |
| F04/F07 | 并发修正只允许一个修订成功；并发不同属性不会突破条数上限；类型、敏感凭据、额外字段和实时属性拒绝 |
| F05 | 稳定事实必须匹配当前运行已登记的工具结果摘要和证据字段；篡改事实值拒绝；来源撤销后不可继续作为事实使用 |
| F11 | 记忆来源设施故障按 Agent 策略降级并记录 warnings，严格策略拒绝执行；授权错误不能降级放行；必要事实返回业务工具查询要求 |
| 权限与界面 | 真实管理 Token 和真实 HMAC 业务委托；不能覆盖主体或读取同号其他主体；Token 撤销即时生效；来源不可见不补读标题；管理页确认、修正冲突保留输入、有效期、策略、开关与删除进度 |
