## 2026-10-04 三层记忆调整

会话层复用既有消息与上下文；归档和人物画像由独立 `memory.sweep` 定时扫描及统一后台运行生成，不接入对话提交或完成钩子。画像属性改为渠道配置，历史业务属性通过迁移保留；新渠道只提供通用默认属性。生成的画像先待确认，明确确认后才参与后续运行。

| 验收 | 本次自动验证内容 |
| --- | --- |
| MEM-F02/F12 | 真实会话运行结束后未生成长期记忆；后台两次模型调用生成归档和候选，确认后下一会话读取归档与画像；可读归档来源显示“会话归档” |
| MEM-F13 | 归档任一消息来源删除后整段归档及未确认画像失效；独立确认的画像保留；遗忘归档同时阻断生成运行内容读取 |
| MEM-F14 | 并发重复扫描不重复创建；模型失败沿用同一来源批次重试；关闭、清空、来源删除和权限撤销阻断迟到写回；清空后新消息仍能进入新任务 |
| MEM-F15 | 自定义属性与 JSON Schema 校验，空属性列表、渠道隔离、旧渠道隐式及显式属性迁移兼容；页面按属性定义编辑数组，后台失败任务可查运行与重试 |
| 迁移与运行边界 | `0033` 降级/升级及旧版运行快照兼容；发布 Agent 的冻结记忆声明可读取记忆，无须重复登记 Agent 策略；检索失败仍按原 OMIT/FAIL 策略处理 |

## 2026-10-04 后台取消与临时限流修复

修复记忆写回和运行终态分开提交导致的取消后回写，以及准入限流被永久标记为 SKIPPED 的问题。新增 9 项回归用例；其中 7 项在修改前复现失败，修改后全部通过。

| 边界 | 验证结果 |
| --- | --- |
| 最终写回前取消、超过截止时间、租约过期或被新执行器接管 | 旧执行器不保存归档或画像，不把整理任务标记为完成；已取消任务后续扫描停止，租约恢复复用已保存模型结果 |
| 成功终态保存失败 | 记忆、整理完成状态与成功事件一起回滚；已成功提交后再取消仍保持成功，终态和结果事件各一次，运行资源正常释放 |
| 平台与渠道真实并发额度占满后释放 | 任务保留同一批次和生成轮次，退避前不提交，退避到期后并发扫描只受理一次并完成整理 |
| 并发扫描的限流错误迟到 | 不覆盖另一扫描已完成的受理状态、运行引用或重试时间 |
