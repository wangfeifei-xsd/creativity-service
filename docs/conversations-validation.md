# 12 会话管理验收记录

日期：2026-10-02；实现与边界见 [交接](conversations.md)。集成用例使用本机 Docker PostgreSQL、Redis 的独立测试范围；运行定义、模型事件与对象存储仅在测试内提供夹具，不代表已完成供应商或业务联调。

| 验收 | 自动验证范围 |
| --- | --- |
| SES-A01 | 六个不同消息并发仅一条受理，其余 `SESSION_BUSY`；预算拒绝不遗留消息、轮次、run、幂等、占用或 outbox |
| SES-A02 | 同消息并发、改用 HTTP 幂等键、解析器暂不可用、归档后重放均返回原关系；修改正文或输入拒绝；浏览器网络失败保留正文并复用客户端标识 |
| SES-A03 | 文本及工具片段保存为未完成；取消保留部分内容；迟到输出不反转终态；终态提交后退出由恢复服务补偿 |
| SES-A04 | 归档拒绝新消息，恢复后的消息及轮次顺序连续；标题修改不改正文；历史分页固定首屏上界 |
| SES-A05 | 排队及运行中删除均立即阻断历史、发言、run、上下文和附件；取消与清理意图同事务；本地清理不冒充全图完成；预览区分独立记忆来源 |
| SES-A06 | 新轮次采用新版本，历史版本不变；不兼容契约提示新会话；普通追问形成新 run 并携带已确认条件与原问题 |
| SES-F01/F12 | 渠道、环境、数据域与主体隔离；跨渠道 Agent、无效附件拒绝；HTTP 正文覆盖渠道拒绝；真实 Redis Token 到期后附件与删除进度返回 401 |
| 上下文 | 当前正文、输入与必要指令优先；摘要来源、版本和省略序号持久化；删除消息后原摘要和已冻结上下文不能再用；缺少受控摘要生成端口拒绝生成 |

浏览器用例使用真实 Chrome 与接口夹具，覆盖消息终态、重试、归档恢复、删除进度及 390 像素窄屏。迁移升降级和实际 schema 审查复用运行模块的完整迁移链验证。
