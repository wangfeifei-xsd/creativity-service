| 验收 | 证据及结果 |
| --- | --- |
| EVL-A01 固定条件比较 | 冻结版本、依赖、样本和标签；同批/历史基线对齐；完整分母及逐条差异；两种结构各 6 条固定样本 |

| EVL-A03 关键阻断 | 越权、泄密、虚构实体和计算类别走不可豁免门禁；即使普通阈值为零仍拒绝关键失败 |

| EVL-A06 来源删除 | 样本、报告及发布门禁立即失效；原主体 run 转管理样本的删除可回溯；派生 run 原文禁止读取，清理器可清除内容 |
| 导入及权限 | CSV 中文与带换行字段、JSONL 错误行、全批提交；标签修改生成版本；渠道及独立敏感原文权限分别校验 |

## 12 条样本与证据

[样本清单](../examples/evaluations/generated/manifest.json) 标明两种结构、标签来源及框架适用范围。[文本条目报告](evaluations-evidence/text_items.report.json) 与 [数列汇总报告](evaluations-evidence/numeric_summary.report.json) 保留完整运行和依赖关联。每组为 2 条通过、1 条无效、3 条未通过，关键失败导致发布阻断；这正是包含反例的门禁验收预期。

这些报告使用隔离测试渠道及固定模型响应，测试结束后数据库被清理。报告文件可追溯本次执行结构及摘要，不能在其他渠道导入为发布凭据。没有启用语义模型裁判，真实模型和 MCP 证据交由 26 补齐；25 负责全图清理、保存期和备份恢复验证。
