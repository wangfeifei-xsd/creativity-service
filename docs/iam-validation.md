# 04 验证记录

日期：2026-10-02。环境：macOS arm64、Python 3.12.7、PostgreSQL 17、Redis 7；沿用工程依赖。对应 [交接说明](iam.md)。

| 项目 | 证据 |
| --- | --- |
| 账号及初始凭据 | 初始管理员命令只能初始化一次；首次 Token 仅可改密/退出；摘要不包含明文，改密后旧 Token 失效 |
| IAM-A04/A09 | builder 可以编辑已授权版本，不能正式发布、导出、自增角色或权限；伪造角色/渠道头无效；服务端导航和动作同步过滤 |
| 独立动作 | 普通管理员不能自行授予发布/原文/导出；单独授予 prod 指定版本发布后仅该目标允许；不能由角色修改激活超出操作者范围的潜在权限 |
| IAM-A05 | 成员移除/账号停用/密码重置立即拒绝旧 Token；浏览器和 worker 下一执行边界重查权限；运行身份来源不随工作区切换改变 |
| IAM-A06 | 系统账号治理与审计可用；相同管理员无敏感原文授权时不能读取运行、快照或文件内容 |
| IAM-A07 | 同账号在两个渠道独立授权，移除其中一个渠道成员不撤销另一个 Token 或成员 |
| IAM-A08 | 32 字节随机 Token、Redis 摘要定位、固定 TTL；普通请求不续期；去掉 TTL、到期或删除 KV 均返回 401 |
| IAM-A10 | Redis 登录/校验故障返回 503；撤销清理失败后数据库当前状态仍阻断，补偿可重复执行且不误删随后签发的 Token |
| IAM-A11 | 8 路规范化同名账号创建只成功一次；8 路同渠道同账号首次成员创建只成功一次；6 路同自然键授权创建只成功一次，其余返回 409 |
| IAM-A13 | 同一成员及授权服务供渠道与成员接口复用；修改/撤销后相同 Token 的下一授权检查立即变化 |
| 用途与工作区 | login/management/service 两两拒绝互换；两路竞争切换仅一次成功，旧 Token 与索引失效；篡改渠道/数据域拒绝 |
| 主体与 Key 交接 | 委托主体必须存在且匹配完整 Scope；主体动作缩减、Key 到期/停用立即阻断；服务 Token 到期不晚于 Key |
| 审计 | 成功/拒绝结果、平台/渠道归属、实际受影响范围及脱敏字段验证；审计没有密码和 Token |
| 文件边界 | 公共 ArtifactService 装配真实 IAM；对象读取期间撤销 Token，交付前拒绝返回字节；对象存储使用内存夹具，核心既有用例另验证真实 S3 |
| 组合事务 | 首位成员初始化与调用方渠道事务一起回滚，不留下成员、授权或成功审计孤儿记录 |
| 缺失依赖 | 未接入渠道目录时系统会话仍可用，业务工作区列表/进入返回 503；无生产允许全部替身 |
