# 25 删除传播与数据保留验收

验证日期：2026-10-03。对应 [执行方案](../../代码编写执行方案/25-删除传播与数据保留.md)；部署操作和恢复证明格式见 [交接说明](data-lifecycle.md)。本轮使用真实 PostgreSQL、Redis 和 MinIO，数据库测试按独立 schema 隔离；模型输出使用明确的受控替身。

## 组合覆盖

| 需求及场景 | 验证结果与入口 |
| --- | --- |
| GLO-A05 / SES-A05 / RUN-A07 | 会话删除清除消息、摘要、上下文、运行正文、checkpoint、事件和派生文件；永久标记先于分批清理生效 |
| MEM-A04/A05 | 单项/清空任务完成，失效来源记忆撤销并清空历史及主体名称；人工独立依据保留；新运行可读取独立记忆，原来源运行保持阻断 |
| EVL-A06 | 完整等价成功运行支持独立样本，删除其中一个后保留另一个依据；无来源支持的断言拒绝；报告内容清空并标记不可复现 |
| 删除后模型返回、Worker 重投 | 既有运行/编排边界用例与新增重复清理投递验证：已删内容不能提交或恢复，旧租约回收不重复生成结果 |
| 清理中上传与清理失败 | 暂存上传停在对象返回前，完成删除后释放上传：登记被拒绝且对象回收；对象删除失败保留阻断，重试后生成证明 |
| 记忆提前刷新 | 删除来源后、Worker 尚未规划前读取记忆，随后仍阻断旧派生文件，并纳入原任务的清理进度 |
| 缓存来源传播 | 真实 Redis 缓存带来源运行；无证据附件的缓存复用也登记来源关系，删除原运行立即阻断复用运行 |
| 两渠道同号 | 同编号的会话、消息、运行和来源关系仅清理目标渠道；对象扫描使用渠道前缀 |
| 跨主体范围 | 来源主体删除立即阻断其他主体的派生文件，保留共享配置与无关联的独立文件 |
| 保留周期 | 25 小时事件清理不损坏完整输入；31 天运行受 60 天渠道覆盖保护，恢复默认 30 天后清理；暂停继续清理，归档 91 天后清理共享配置 |
| 元数据 365 天 | 删除 366 天前已结算账本及关联事件/预占和旧审计；364 天已结算、366 天待结算账本继续保留 |
| 迟到计量 | 删除后迟报数字仍幂等结算；用量正文及诊断字符串不进入持久化事件 |
| 旧库与旧对象恢复 | 保存删除前数据库及对象，删除后恢复旧副本；独立屏障拒绝内容，重放最新清单清除副本并输出证明 |
| 清单与屏障竞争 | 缺失/过旧清单拒绝恢复；备份初始化不能覆盖已封锁状态；重放不能解除并发产生的新恢复封锁 |
| HTTP 与 UI | 真实 HTTP 预览、受理、进度接口及客户端范围覆盖拒绝；浏览器验证中文预览、原文退出、失败重试和完成进度 |

新增专项位于 `tests/integration/data_lifecycle/`、`tests/integration/evaluations/test_deletion_lifecycle.py`、`tests/integration/usage/test_deleted_content_usage.py`。原记忆测试同步加强为“原来源运行被阻断，新运行仍可读取独立依据”，不再在已删来源运行中继续加载记忆。
