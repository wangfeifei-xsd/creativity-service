# 模型与迁移兼容

当前结构以 [catalog.json](catalog.json)、[模块字段索引](README.md) 和 [初始化 SQL](../../sql/README.md) 为准。历史实现过程与验证记录查 Git 历史，本文件只维护仍影响升级与读取的边界。

| 变更 | 当前处理与入口 |
| --- | --- |
| 初始基线合并 | `0001_initial.py` 冻结至 `0034_admission_indexes`，之后的 `0035`–`0046` 仍逐项执行；旧库衔接见 [初始迁移基线](../../sql/README.md#初始迁移基线) |
| 渠道、环境与主体 | 移除旧数据域和工作区分类；已有内容、主体冲突、恢复屏障及登录兼容见 [渠道环境模型升级](../../sql/README.md#渠道环境模型升级) |
| 渠道管理员发布权限 | 内置权限及历史授权补齐规则见 [渠道管理员默认发布权限](../../sql/README.md#渠道管理员默认发布权限) |
| 资源管理简化 | 提示词、路由、工具与技能使用稳定资源 ID 和当前配置；`0043_resource_management` 拆分历史不同配置，保留运行快照，详见 [资源管理方案](../../../需求文档/18-资源管理简化修改方案.md) |
| MCP 凭据 | `0044` 引入服务间鉴权，`0046` 转换为直接存储；转换与回退边界见 [MCP 凭据直接存储](../../sql/README.md#mcp-凭据直接存储) |
| 固定业务 HTTP 接入 | `0045` 移除旧连接、测试表及对应凭据，业务工具统一走 MCP；见 [移除固定业务 HTTP 接入](../../sql/README.md#移除固定业务-http-接入) |

匹配、风险与分析属于业务方可选配置示例，原 12 张未实现领域表已撤销。平台通过通用配置、运行、证据、产物与评测承载结果，领域数据由业务 MCP/源系统维护。

配置与运行 JSON 的当前结构见 [内部契约](../../contracts/internal/)；已受理运行使用冻结的配置和内容，不能被后续编辑覆盖。删除与恢复边界见 [数据生命周期](../operations.md#data-lifecycle)。结构变更的维护与校验统一按 [SQL 维护说明](../../sql/README.md#维护与验证) 执行。
