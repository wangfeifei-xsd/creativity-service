## 事务与治理补充

- 6 路同规范化渠道编码开通只成功一次；其余返回 409。
- 注入首位管理员授权失败，渠道主档、环境、数据域和系统编码索引全部回滚。
- 注入 Key 身份索引写入失败，Key 主记录和成功审计全部回滚，不留下可调用孤儿凭据。
- 系统渠道初始化可重复执行；它不进入业务渠道目录。
- 只有一个数据域权限的管理人员不能暂停覆盖其他未授权范围的整渠道。
- 新环境数据域通过平台明确指定管理员，使用同一 IAM 成员记录和新域授权；普通多环境成员与资源授权按真实环境/域配对验证。
- 归档预览及实际提交检查有效 Key 和未终结任务；任务检查器返回未完成数时阻止归档。未安装运行模块时确认无 runs 表；安装后缺少检查器则拒绝归档。
- 创建、轮换响应禁止缓存；列表与审计无密钥明文或摘要；审计返回中文动作、对象名称及实际修改字段。
- 仅平台治理身份不能签发业务 Key 或通过业务认证；平台用量查询必须明确渠道范围，并在系统渠道审计中保存实际统计范围。
