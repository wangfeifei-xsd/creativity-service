# 18 验证记录

日期：2026-10-02。实现与配置说明见 [业务接入交接](integrations.md)。验证在 Python 3.12、真实本地 PostgreSQL/Redis 与 Chrome 中执行；源业务数据使用明确的测试适配器，不代表租号/陪玩后端已联通。

| 验证项 | 结果与范围 |
| --- | --- |
| 接入专项测试 | `pytest -q tests/test_business_contracts.py tests/integration/integrations`：29 项通过，11 项协议/转换验证、18 项真实 PostgreSQL/Redis 集成验证 |
| 委托验签及映射顺序 | 伪造签名在数据域查询前拒绝；错误 issuer/audience、过期、跨渠道/环境、扩大权限、未知源数据域全部拒绝 |
| 防重放 | 8 路同凭证并发只保留一条 nonce；改变主体、正文或目标资源拒绝；HTTP 实际正文不匹配拒绝 |
| 独立轮换 | API Key 轮换保持 client_id 及同一 nonce 记录；HMAC 新 kid 保留 rotated_from，重叠期旧委托可重发，吊销后立即拒绝；列表不返回签名秘密或密文引用 |
| 匿名与 Worker | 匿名只读字典可用，记忆权限请求被拒绝；委托过期后普通请求拒绝，Worker 缺少当前源权限读取器拒绝；当前权限可收窄、不可扩大 |
| 18/11 联合受理 | 4 路并发重发、轮换 API Key 后再次重发，实际数据库只有一个 run 和一条 dispatch_outbox；运行保留 delegation_id，不保留 Token。使用固定测试定义、预先初始化的内容恢复范围，受理与重放使用真实 IAM |
| 业务转换 | 不支持、无权限、超时、无数据、下架、缺失和重定向分别保留错误；源字段变更、字典名称缺失、不完整分页拒绝；显式字段映射不猜测字段 |
| 出站与工具交接 | 目的地/路径逃逸被拒绝，请求绑定源数据域并携带 request_id/run_id；工具桥接保留实际 run_id，连接修订变化使旧绑定失效 |
| 配置与契约测试 | 同名连接 5 路并发只接受一个；跨渠道对象不可见；测试只保存能力、固定结论和条数，输入及业务响应原文未落测试表；修改配置使旧验证失效 |
| 跨语言向量 | Python 与 Node.js 独立实现对包含中文正文的 POST、带查询串的 GET 生成完全相同的完整委托头；固定原文摘要一致 |
| 前端工程 | `pnpm check` 通过：接口生成一致、TypeScript、ESLint、14 项 Vitest 与生产构建；现有单包体积提示保留 |
| 浏览器 | 3 项 Chrome 用例通过：列表/详情/能力名称、409 后保留表单及无身份正文、390 px 窄屏配置。截图已检查，无横向溢出，字段和保存按钮可操作 |
| 后端工程 | 当前并行工作树 `make check` 通过：Ruff、mypy 198 个源文件、128 项全量非集成测试、全部已实现模块契约、数据模型归档和存储静态审查 |
| 迁移 | 独立 schema 的全量升级、重复升级、降级、离线 SQL 和实际注释/普通索引审查通过；本地开发库已从 0010_tools 升级到 0019_parallel_runs，`audit --database` 通过 |
