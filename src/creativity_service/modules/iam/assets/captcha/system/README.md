# 验证码风景图库

这 10 张公共风景素材用于系统渠道的平台登录验证，参考桌面壁纸的自然风光构图。素材来源于 Wikimedia Commons，原文件均声明采用 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。不包含 Windows 标识或 Microsoft 官方壁纸。

图片已裁切为 2:1、缩放为 640×320 JPEG 并移除元数据；青丘晴空选取原图下方的山丘区域。服务端每次生成挑战时随机选取一张，在副本上裁切拼块和缺口，不从外部网络加载图片。
